# 背景

> 该项目聚焦于课题1（电力系统规划）的自动求解模式，不依赖具体的模型规则和扣减顺序。输入数据包含：课题1的输入数据（通过excel表格）和课题2独有的成本参数（系统返回默认值，前端支持用户修改），前端需要渲染这些输入数据。输出数据包含：各个电源的决策变量、基于决策变量计算的有功功率和成本。

## 架构

> 核心算法（power_opt）分层，依赖单向、禁止反向 import。完整规则见 `.claude/skills/architecture_rule.md`、`data_rule.md`、`code_basic_rule.md`；README 自身的同步维护规则见 `.claude/skills/readme_rule.md`（代码改了 README 不同步 = 改动未完成）。

```
main.py / run.py        入口层：main.py 命令行全量出口；run.py 服务对外唯一显式接口
  ↓
reader.py               公共层：系统公共输入
  ↓
model/units/*.py        单元层：一电源一文件一类，自包含
  ↓
model/context.py        系统层：跨电源耦合与全局约束
  ↓
solve.py                组装层：循环组装 → 目标函数 → 调用求解
  ↓
solution.py             取值层：Solution 纯数据 + 对拍件落盘
  ↓
plot.py / analysis_export.py   出图层与分析层：CSV / PNG / mat / txt / json
```

各层编写规则：

| 模块                                                    | 职责         | 编写规则                                                                                                                                                                                                                                                                     |
| :------------------------------------------------------ | :----------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [reader.py](power_opt/reader.py)                         | 系统公共输入 | 只装系统公共输入，电源专属输入在对应单元模块读取；遵守公共数据规则：类 docstring 必写、字段英文+行尾中文注释（语义+单位）、大输入类按主题分类组合、缺列/缺值立即报错禁止补 0                                                                                                 |
| [model/units/*.py](power_opt/model/units/)               | 单元层       | 一电源一文件一类，inputs/vars 为实例属性；四步生命周期顺序固定：`load(inp)` → `add_vars(m)` → `add_constraints(m, inp, sv)` → `add_cost(dt, econ)`；统一胖签名，用不到的入参直接忽略；add_cost 返回键名是对外成本合同，冻结；变量建序、约束行序、成本加法顺序冻结 |
| [model/context.py](power_opt/model/context.py)           | 系统层       | 只读 RegisteredUnits 注册表做全局约束与耦合；耦合只发生在本层，禁止把耦合逻辑塞回单元                                                                                                                                                                                        |
| [solve.py](power_opt/solve.py)                           | 组装层       | 全项目唯一调`optimize()`、设求解参数的文件；UNITS 列表顺序 = 变量建序，冻结，新电源插入位置须对照理论文档；目标函数 = Σ各单元 add_cost + 系统残项，加法顺序冻结；每次求解后四项核对（变量规模/约束规模/求解状态/目标值）进日志再谈结论                                    |
| [solution.py](power_opt/solution.py)                     | 取值层       | Solution 类是唯一取值出口，纯数据，不做前端口径组装；含 values / costs / four_items / slacks 及派生量；时序结果 CSV 与 结果.json 为对拍件，列集冻结                                                                                                                          |
| [plot.py](power_opt/plot.py)                             | 出图层       | Plot 类只消费 Solution；21 设备列堆叠顺序冻结，发电为正、充电抽水为负                                                                                                                                                                                                        |
| [analysis_export.py](power_opt/analysis_export.py)       | 分析层       | AnalysisExport 只消费 (inp, solution)；metrics / 分析五表 / views / 落盘（00~07 PNG、.mat、摘要.txt）均为 MATLAB 对拍口径，冻结                                                                                                                                              |
| [main.py](power_opt/main.py) / [run.py](power_opt/run.py) | 入口层       | main.py 为命令行全量出口（求解+存储结果保存）；run.py 为算法包对外唯一入口，服务只 import run（RunConfig → run()/run_with_outputs()），禁止 sys.path 直插、禁止外部改写 config                                                                                              |

## POST /api/datasets

> **传参**
> file: binary #上传二进制模板文件（可选）

> **return: 传递file**

```json
{
  "datasetId": "ds_9bfeec0820e3",
  "area": "海南",
  "year": 2030,
  "categories": [
    {
      "name": "",
      "items": [
        {
          "name": "",
          "tables": [
            {
              "name": "",
              "columns": [],
              "rows": [
                {}
              ]
            }
            // ... 
          ],
          "curve": {
            "sheet": "负荷-8760",
            "filterBy": [
              "区域"
            ],
            "match": "exact"
          }
        }
      ]
    }
    // ...
  ], // 需要在前端展示的用户上传的模板数据，有表格的需要渲染表格
  "config": {}, // 需要在前端展示的基础配置，支持用户修改
  "fixedParams": [] // 需要在前端展示的基础配置，不支持用户修改
```

```json
	"config": {}
}
```
