| 8 | 生物质可调 | 推导 | 生物质总出力 − 生物质最小技术出力 |

| 26 | 弃风 | 直接聚合 | Σ P_wind_curt |
| 27 | 弃光 | 直接聚合 | Σ P_pv_curt |

符号说明（变量名同 series/labels，参数为模型输入常数）：

| 符号 | 含义 |
|---|---|
| P_nuc | 核电出力（逐机组） |
| P_th / u_th | 煤电出力 / 煤电开机状态（1=开） |
| P_th_min | 煤电单机最小技术出力（Pmin，参数） |
| P_gas / u_gas | 气电出力 / 气电开机状态（1=开） |
| P_gas_min | 气电单机最小技术出力（参数） |
| P_bio | 生物质出力 |
| P_bio_min | 生物质单机最小技术出力（参数） |
| m_bio | 生物质检修标记（常数，1=检修） |
| P_hyd_ror | 径流式水电出力 |
| P_hyd_res | 库容式水电出力 |
| P_wind / P_pv | 风电 / 光伏出力（系统电站） |
| P_wind_curt / P_pv_curt | 弃风 / 弃光 |
| P_shed | 未供电负荷（失负荷） |
| P_D | 修正后负荷（需求响应后） |
| P_load | 收资本地负荷 |
| R_th_hot / R_hyd_hot | 煤电 / 水电热备用 |
| E_hyd_curt | 水电弃水电量（MWh，机组×月） |
