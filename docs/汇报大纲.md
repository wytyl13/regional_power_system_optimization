# 工作汇报大纲

## 项目原理（一分钟版）

本项目把"每台机组每小时怎么发电"写成一道数学题，用**混合整数线性规划（MILP）**求解：

- **决策变量**：每台机组每小时的出力（连续，MW）+ 开机还是停机（0/1 整数）
- **约束**：功率平衡（发电=用电）、出力上下限、爬坡、最小开停机时长、检修、备用
- **目标函数**：总成本最小

"混合整数" = 变量里既有连续量又有 0/1；"线性" = 约束和目标都是线性式
（煤电的二次成本曲线按 6 节点分段线性化）。求解器 Gurobi 在满足全部约束的
方案里找成本最低的一个。

## 能拿到什么结果

| 结果 | 现状 |
|---|---|
| 逐机组逐时调度方案 | ✅ 每台机组每小时出力、开停机、热/冷备用、弃风弃光、储能荷电量 |
| 总成本 | ✅ 目标函数值（燃料+启停+固定运维+碳排+环保+弃电惩罚） |
| 单个电源成本 | 模型内部已逐类逐项计算（煤/气/核/生/储的燃料、启停、碳排等），输出是小改动；当前结果文件里只有总成本 |
| 工作位置图 | ✅ 27 列，对齐老版系统口径 |
| 运行指标 | ✅ 未供电量、失负荷小时、最大缺口、新能源利用率、碳排、备用裕度 |
| 电源机组规划 | ❌ 非本模型职责：机组组合是**输入**（收资给定），模型只决定"这些机组怎么运行最省"；检修计划同样是输入，不做自动排检修。能给规划的参考信息：缺口分析、充裕度、利用率、碳排；真正的容量规划需扩模型（容量改为决策变量） |
