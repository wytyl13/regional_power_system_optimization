# 海南2030年算例

打开本文件夹中的 `synergy_hainan_30.m` 并运行。主程序、三份输入表格和本说明均在同一目录，整个文件夹可复制或移动到任意位置，无需修改读取路径。原江苏脚本和原始收资文件保留。

主程序保持“全部输入—决策变量—分设备约束—目标函数—求解—结果图像”的顺序。输入读取及计算均在主程序内，测试脚本不参与日常运行。运行环境为已配置 YALMIP 和 Gurobi 的 MATLAB。

## 输入文件及运行设置

本目录的三个 Excel 文件分别为：

| 文件 | 内容 |
| --- | --- |
| 分区机组信息表.xlsx | 分区、各类设备、2030年检修计划、未纳入机组、中文字段及补参说明 |
| 算例系统参数.xlsx | 成本、备用、负荷与需求响应参数、水电月出力、友好站8760小时出力、煤电碳排节点 |
| 运行数据.xlsx | 海南8760小时负荷、风电和光伏容量因子及负荷换算基准 |

读取路径通过 `fileparts(mfilename('fullpath'))` 自动取得主程序所在目录，不依赖固定盘符、上级项目目录或 MATLAB 当前工作目录。移动算例时，请将整个文件夹一起移动，并保留三个表格的文件名。求解日志也写入本目录。

脚本输入段默认设置为：

```matlab
startTime = datetime(2030, 1, 1, 0, 0, 0);
hydrologyScenario = "平水年";
T = 168;
useInterprovincial = false;
useFixedTransfer = false;
```

`T` 可设置为24、168、720或8760等整数小时数，起止时间须在2030年内。水文情景可选“平水年”或“枯水年”。改起点时，各类机组的前一小时检修状态根据计划衔接；煤电和气电如处于检修期，会使用停机初态及已检修小时数，否则使用表内初始运行状态、功率和持续小时数。这些初值是本次独立仿真的条件，不是上一轮求解结果。

仅省间互济和既定跨区送电保留开关。其他设备和系统约束直接建立。没有径流式水电和光热资产时，相应设备表保留表头。外部交换数据尚未提供，启用前需填写正式曲线或两端省份的完整互济数据，不能将空表或“测试通道”当成真实供电能力。

## 纳入的容量和口径

全省统一 `AreaID=1`、`AreaName=海南`、`ProvinceID=HN`，仍保留自动识别分区的代码。

| 设备 | 2030年纳入容量（MW） | 处理 |
| --- | ---: | --- |
| 煤电 | 3240 | 12台，源非供暖受阻率3% |
| 气电 | 2740 | 3台，源非供暖受阻率15% |
| 核电 | 3825 | 5台，源投产日期均早于2030年 |
| 生物质及三余 | 970 | 7项，源非供暖受阻率24% |
| 抽水蓄能 | 600 | 琼中抽蓄，2031年后项目暂不纳入 |
| 常规水电 | 1800 | 两座水电均按用户确认归属海南，保留原名称 |
| 普通风电 | 4570 | 190MW陆风和4380MW海风容量加权曲线 |
| 普通光伏 | 11660 | 全省单一光伏曲线 |
| 独立新型储能 | 180 | 源转换效率90%、充电时长2小时 |
| 新能源友好电站 | 风200、光200、储50 | 风光储按单独模型列报 |

容量由源表“万千瓦”乘10转换为MW。煤、气、生物质的出力上限为额定容量乘以 `1-DERATE_RATE`，最小出力按额定容量乘以非供暖最小技术出力率；固定运维按额定容量计算。

友好电站采用独立列报口径：普通风光和独立储能取各自表值，友好电站另列，不从普通设备容量中扣减。站内风光采用海南对应容量因子，储能只能由站内风光充电。若后续收资确认普通设备总量已包含友好站，需要在输入表中扣除重叠容量。

储能源“转换效率”解释为往返效率，充、放电各取其平方根。SOC上下限暂取10%和90%；能量容量按 `功率×源充电时长×单向充电效率/0.8` 计算，使源充电时长对应SOC下限至上限，而不是直接当作放电时长。友好站缺少时长，暂按2小时补入。

## 保留的源数据差异

1. 原始8760负荷曲线乘最大负荷14210MW，对应841.032810亿kWh，比汇总表807亿kWh高约4.22%。当前采用原8760曲线，没有为匹配807亿kWh而改写曲线。
2. 源光伏曲线的电站名称逐行递增，实际只有一个光伏资产。因此按海南区域和日期读取365天，不按这些名称生成额外机组。
3. “海风2024度夏”对应曲线表中的“海风”，已明确映射。
4. 生物质通用最小出力率与非供暖列存在差异。当前统一采用非供暖61%和受阻24%，同时保留通用原值供核对。
5. 未来机组保存在“未纳入机组”。4039、4049等原始投产年份疑似笔误，未擅自改写；它们均不影响2030年的在场容量。
6. 煤电检修优先采用逐日标记，不把起始天0解释成上一年日期。其他机组非运行周按周一至周日展开，含首尾周，首尾不足七天的周均计入。

## 补充参数与模型限制

源表提供的容量、曲线、受阻率、需求响应能力、旋转/停机备用比例及检修计划直接使用。缺失的启停时间、爬坡、燃料/运维成本、初值、SOC、储能寿命和需求响应时长等已填入可编辑算例值，逐项列在“参数说明”，不代表海南实测值或2030年预测。

按用户确认的备用口径，总备用（热备用＋冷备用）至少为完整自然周峰荷的10%，其中冷备用至少为周峰荷的5%；不单独设置热备用下限。当前主脚本输入段直接设置 `AdequacyFactor=1.10` 对应的容量充裕度系数及冷备用率0.05，覆盖省级约束表中的旧值，不读取旧 `HotReserveRatio`。需求响应可转移、可削减能力各按源2.5%周峰荷计算。已有168小时结果及下方历史验证采用修改前的备用要求，未因修改代码而自动更新。

**基础算例允许记录失负荷，`ShedMaxRatio=1`，惩罚为28000元/MWh。** 当前不计外部受电，沿用原检修日历后，部分时段供电不足。此设置用于如实计算未供电量，不是补造外部电源，也不表示供电已满足。严格保供可将该参数改为0，缺电情景将报告不可行。例如2030年2月1日19时，在枯水年、原检修及备用要求下，即使乐观计入所有储能满功率和最大需求响应，供电缺口仍至少约744MW；这解释了该跨月情景在严格供电要求下不可行。

**新能源利用率下限默认0。** 海南收资表没有给出这一指标，基础算例保留弃电惩罚并报告实际利用率。原江苏95%下限与海南首周“核电基荷运行”等当前条件冲突，不能直接移植。可在“省级约束”的 `RenewableUtilizationMin` 中输入目标（如0.95），但这将改变可行域，并可能使某些短周期不可行。

核电最小出力按用户要求在主脚本中设为额定容量的50%，覆盖机组表旧值；非检修时可在50%至100%之间调节，检修时为0。机组表尚未同步，当前以主脚本设置为准；既有168小时结果也未重新求解。水电按源月强迫、预想和平均功率建模；源水库调节系数只作资料保存，不重复乘入电量预算。没有另建水头、水位、跨月水量调配或机组检修优化模型。

煤电碳排六节点采用 [IPCC 2006能源卷第2章表2.2](https://www.ipcc-nggip.iges.or.jp/public/2006gl/pdf/2_Volume2/V2_2_Ch2_Stationary_Combustion.pdf) 的烟煤默认因子，气电采用天然气默认因子；发电效率和低负荷修正属于算例假设。碳价、污染物成本也为情景值，未当作海南实际税率或2030预测价格。

全年能量、碳预算在短周期中作为可用预算，不自动按天分摊。连续滚动计算还需要维护剩余预算、储能末态和机组状态；当前脚本是可设置周期的独立求解，不是自动滚动求解器。输入覆盖8760小时不代表全年大规模整数模型已完成求解。

## 供暖期与非供暖期最小技术出力

`分区机组信息表.xlsx` 的煤电、气电、生物质页新增 `MIN_RATIO_HEATING`（供暖期最小技术出力率）与 `MIN_RATIO_NONHEATING`（非供暖期最小技术出力率），取自 `数据模版-海南.xlsx` 对应机组的两列。当前两期数值相同：煤电45%、气电1%、生物质61%。比例乘以额定容量 `CAP` 得到开机时的最小出力，单位MW。

`供暖期设置` 页按分区设置日历。海南分区1已启用每年11月15日至次年3月15日，包含起止日全天；`Enabled=1` 按日历切换，`Enabled=0` 为全年非供暖。新增分区时应添加对应 `ZoneID` 的日历行。代码根据仿真每小时日期和机组所在分区选择下限，停机时下限为0。

上述三类机组原 `MIN_POWER_GEN` 保留历史值，不再决定运行下限；其他设备不受影响。煤电六个分段节点覆盖两期下限的较小值至可用上限，原碳排节点按原功率位置线性重采样；若未来下限低于原节点范围，会按最低段线性外推，需要精确排放曲线时应更新碳排参数。当前两期数值相同，不改变原节点。受阻率及最大可用出力仍采用原设置。

## 结果

抽蓄热备用已按0928版PDF第30—31页更新：非抽水、非检修的机组可提供热备用，包括不发电的待机状态；发电功率与备用之和不超过最大发电功率，备用还受时段末最低SOC以上的可用水能限制，并须持续一个调度时段（当前1小时）。抽水或检修时备用为0。该修改不自动更新此前保存的168小时结果。

结果保留在MATLAB工作区，包括各设备逐时功率、储能能量、备用、弃电、总成本、实际新能源利用率、未供电电量 `EnergyNotServed`、缺电小时数 `LossOfLoadHours`、最大缺口 `MaxLoadShortfall` 及功率平衡残差。图像采用逐小时柱状堆叠图，充电和抽水在负半轴，友好站风、光和储能单独区分；红色“未供电负荷”表示缺口，不是电源出力。海南单分区只输出一张全省图，避免重复。

默认图像展示起点后168小时。在图像段修改 `plotStartHour` 和 `plotHours` 可查看仿真区间内其他时段。

Gurobi默认时限1800秒、相对间隙1%，采用优先寻找可行解的搜索策略。达到时限时，只有存在通过残差检查的可行解才输出结果；无可行解、不可行和无界分别提示，日志保存在本目录。
